# 🎓 Student Management System (SQL Mini Project)

This project demonstrates a complete SQL-based system to manage students and courses.

---

## 📌 Features
- Create database and tables
- Insert, update, delete data
- Perform joins and queries
- Use procedures and triggers

---

## 🧠 Concepts Used
- DDL, DML
- JOIN (INNER, LEFT)
- GROUP BY, HAVING
- LIKE
- Stored Procedures
- Triggers

---

## 🎯 Objective
To manage student-course relationships and perform data analysis.

---

## 📂 Structure
- schema.sql → tables
- data.sql → sample data
- queries.sql → operations
- procedures.sql → reusable logic
- triggers.sql → automation

---

🔥 This project covers end-to-end SQL concepts for interviews.
